## Sobre mim

Estudante de **Big Data e Inteligência Artificial** na **PUC Goiás**, com formatura prevista para **julho de 2027**.

Gosto de transformar dados em soluções: da coleta e organização até modelos de machine learning e aplicações de IA. Meu objetivo é atuar como engenheiro de dados e de IA, construindo projetos de ponta a ponta.
